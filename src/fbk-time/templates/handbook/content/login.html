Anmeldung und Passwort

Anmelden

Auf der Startseite geben Sie Benutzername und Passwort ein. Der Benutzername gilt unabhängig von Groß- und Kleinschreibung. Beim Passwort zählt jedes Zeichen.

Schlägt die Anmeldung fehl, erscheint eine allgemeine Meldung. Aus Sicherheitsgründen sagt die Anwendung Ihnen nicht, ob Benutzername oder Passwort falsch waren.

Nach mehreren fehlgeschlagenen Anmeldeversuchen wird Ihr Konto vorübergehend gesperrt. Nach Ablauf der Sperrdauer können Sie sich wieder anmelden; vorher kann ein Manager Sie manuell entsperren. Die genauen Schwellenwerte und Sperrfristen legt die Administration fest.

Nach jedem Fehlversuch wartet die Anwendung etwas länger, bis sie den nächsten Versuch annimmt.

Konten ohne Aktivität werden nach einer eingestellten Frist automatisch deaktiviert. Reaktivieren kann sie ein Manager oder Admin.

Erstes Passwort

Passwort ändern

Ihr Passwort ändern Sie auf der Profilseite (Benutzermenü → Mein Profil) im Abschnitt Sicherheit. Zur Bestätigung geben Sie das aktuelle Passwort ein; das neue Passwort tippen Sie zweimal.

Die geltenden Anforderungen (Mindestlänge, erforderliche Zeichenarten) sehen Sie unter dem Eingabefeld. Die genauen Werte legt der Admin fest.

Passwort vergessen

Eine automatische Zurücksetzung per E-Mail gibt es nicht. Wenn Sie Ihr Passwort vergessen haben, vergibt ein Manager oder Admin ein neues Startpasswort. Der Ablauf ist dann wie bei der Erstanmeldung: Beim nächsten Login legen Sie ein eigenes Passwort fest.

Abmelden

Sie melden sich über das Benutzermenü oben rechts ab (siehe Kapitel Einleitung). Die Sitzung endet damit sofort.

Das Schließen des Browserfensters allein reicht nicht aus, um die Sitzung sofort zu beenden. An gemeinsam genutzten Arbeitsplätzen sollten Sie sich daher immer explizit abmelden.
